# NexaPress

**軽量・安全・拡張可能な、PHP製コンテンツ管理システム。**

NexaPressは、PHPとMySQL／MariaDBで動作するWeb CMSです。  
ブラウザからの初期セットアップに対応し、投稿、固定ページ、メディア、テーマ、ユーザー、拡張機能を管理画面から一元管理できます。

## Overview

NexaPressは、扱いやすさと拡張性を両立したCMSです。

複雑なセットアップを必要とせず、サーバーへファイルを配置した後、ブラウザ上のインストーラーからサイトを構築できます。

管理画面では、コンテンツ作成だけでなく、公開状態、編集履歴、メディア、URL形式、テーマ、ユーザー権限、拡張機能まで管理できます。

### 主な特徴

- ブラウザだけで完了する初期インストール
- 軽量なPHP／MySQL構成
- 投稿・固定ページ・メディアの一元管理
- 役割ごとに分けられたユーザー権限
- 投稿本文の安全化とCSRF対策
- 編集履歴、ゴミ箱、下書きプレビュー
- テーマおよび拡張機能による機能追加
- 管理画面から実行できるCMSアップデート

## Installation

### 1. NexaPressを取得

GitHub Releasesから最新版の本体ZIPをダウンロードします。

```text
nexapress-2.3.0.zip
```

### 2. サーバーへ配置

ZIPを展開し、Webサーバーの公開可能なディレクトリへ配置します。

```text
htdocs/
└─ nexapress-2.3.0/
```

### 3. データベースを作成

NexaPressで使用するMySQLまたはMariaDBのデータベースを作成します。

### 4. インストーラーを開く

ブラウザからNexaPressのURLへアクセスします。

```text
http://localhost/nexapress-2.3.0/
```

未インストールの場合は、自動的にインストーラーへ移動します。

### 5. データベースを設定

以下の情報を入力します。

- データベース名
- データベースのユーザー名
- データベースのパスワード
- データベースホスト
- テーブル接頭辞

### 6. サイトを設定

以下の情報を入力します。

- サイトタイトル
- 管理者ユーザー名
- 管理者パスワード
- 管理者メールアドレス
- 検索エンジンへの表示設定

### 7. 管理画面へログイン

インストール完了後、作成した管理者アカウントでログインします。

```text
サイト：
http://localhost/nexapress-2.3.0/

ログイン画面：
http://localhost/nexapress-2.3.0/admin/login

管理画面：
http://localhost/nexapress-2.3.0/admin
```

## Update

NexaPress 2.2.0以降では、管理画面から本体をアップデートできます。

### 管理画面から更新

1. 管理画面へログインします。
2. サイドメニューの「更新」を開きます。
3. 最新バージョンを確認します。
4. 更新を実行します。

アップデート時には、以下の処理が自動的に行われます。

- 更新パッケージのダウンロード
- ZIPファイルの安全性確認
- SHA-256による整合性確認
- 更新対象ファイルのバックアップ
- メンテナンスモードへの切り替え
- ファイルの更新
- データベースマイグレーション
- バージョン情報の更新
- 更新失敗時のバックアップ復元

NexaPress 2.3.0の更新用ファイル名は以下です。

```text
nexapress-update-2.3.0.zip
```

## Post Management

投稿編集画面では、以下の情報を設定できます。

- タイトル
- スラッグ
- カテゴリ
- 本文
- 抜粋
- アイキャッチ画像
- 公開状態

### 下書きプレビュー

保存済みの下書きは、公開せずにテーマ上の表示を確認できます。

プレビューページには検索エンジン向けのインデックス抑制ヘッダーが設定され、ログイン中の権限を持つユーザーだけが閲覧できます。

### 編集履歴

投稿を更新すると、更新前の内容が編集履歴として保存されます。

編集履歴には以下の情報が記録されます。

- タイトル
- スラッグ
- 抜粋
- 本文
- 公開状態
- カテゴリ
- アイキャッチ画像
- 編集者
- 保存日時

過去の履歴を選択することで、投稿内容を以前の状態へ復元できます。

### ゴミ箱

投稿の削除操作では、すぐにデータを消去せずゴミ箱へ移動します。

ゴミ箱では、以下の操作を行えます。

- 投稿を元の一覧へ復元
- 投稿を完全に削除

## Security

NexaPressでは、投稿管理とアップデート処理に複数の安全対策を実装しています。

### 投稿本文

投稿本文は許可リスト方式で安全化されます。

危険なタグ、イベント属性、不正なURLスキームなどを除去し、文章、画像、リンク、見出し、リスト、テーブルといった投稿に必要なHTMLを保持します。

### 管理画面操作

投稿の作成、更新、削除、公開状態変更、復元、完全削除、編集履歴の復元にはCSRFトークンを使用します。

### 権限管理

ユーザーの役割と投稿所有者に応じて、以下の操作を制御します。

- 投稿閲覧
- 投稿作成
- 自分の投稿の編集
- すべての投稿の編集
- 自分の投稿の削除
- すべての投稿の削除
- 自分の投稿の公開
- すべての投稿の公開

## Extensions

拡張機能は、管理画面の「拡張機能」からZIP形式で追加します。

### 基本構成

```text
sample-extension/
├─ manifest.json
├─ bootstrap.php
└─ admin/
   └─ dashboard.php
```

### `manifest.json`

```json
{
  "id": "sample-extension",
  "name": "サンプル拡張機能",
  "description": "拡張機能の説明です。",
  "version": "1.0.0",
  "bootstrap": "bootstrap.php",
  "admin": {
    "menu_label": "サンプル",
    "dashboard": "admin/dashboard.php"
  }
}
```

`bootstrap`と管理ダッシュボードは、必要な拡張機能だけ指定します。

### 拡張機能で利用できる機能

- 独自ルートの登録
- 管理画面メニューの追加
- 管理ダッシュボードの追加
- 投稿編集画面の拡張
- 管理画面および公開画面へのCSS・JavaScript追加
- NexaPressのフックを利用した処理追加

## Themes

NexaPressには、2つのテーマが同梱されています。

### default

読みやすさと汎用性を重視した標準テーマです。

### MonoEdge

モノトーンを基調とした、コントラストの高いテーマです。

テーマは管理画面の「テーマ設定」から切り替えられます。

## Recommended Operation

NexaPressを安定して運用するため、以下を推奨します。

- PHP、MySQL／MariaDBをサポート対象のバージョンへ保つ
- HTTPS環境で運用する
- 管理者パスワードを十分に長くする
- 不要な管理者アカウントを作成しない
- 定期的にデータベースとファイルをバックアップする
- 本番環境へ更新を適用する前に、複製環境で確認する
- テーマや拡張機能を追加した後は、表示と権限を確認する
- `storage/logs`を定期的に確認する
- `public/uploads`でPHPファイルを実行できないサーバー設定にする
